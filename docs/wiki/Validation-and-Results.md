# 검증 계보와 사용 범위

## 미국 연구의 결과

Stage2B 모델 카드에는 개발 자료에서 Hybrid의 개선 기록이 있지만, 같은 자료를 사용한 회고 평가입니다. 최종 reserve는 필요한 label 대조가 성립하지 않아 점수를 산출할 수 있는 독립 검증 조건을 만족하지 못했습니다.

후속 민감도 연구 역시 신규 독립 final seal로 취급하지 않습니다. 근거의 양성측 coverage, issuer·dependency 집중과 자료 vintage가 한계로 남았습니다. 이 실패와 판정 불가를 한국 웹의 기능 결과로 덮지 않습니다.

## 한국 모델에서 주장할 수 있는 것

한국 과거 시계열의 다변량 이상 정도와 참고 지수를 보여줍니다. 미국 donor는 방향 참고이며 한국의 사건 확률을 검증한 정답셋이 아닙니다.

현재 runtime은 고정 과거 결과를 사용합니다. 실시간 추론과 실행 중 재학습은 지원하지 않으며 production 자격과 독립 과학적 성능 검증이 완료된 모델은 아닙니다.

## API·UI 검증

캐시 무결성, 모델 출력과 API 필드 정합, 지정 사례 replay와 화면 동작은 공학적 검증입니다. 이를 탐지 정확도나 불법행위 판정 능력으로 바꾸어 설명하지 않습니다.

[manifest](../../contracts/final_runtime_manifest.json)는 필요한 과거 결과의 구성을 정의합니다. 해당 자료가 없으면 clone만으로 모델 결과가 생기지 않습니다.

## 남은 과제

한국의 충분한 독립 사건·대조 label, 과거 시점별 정확한 자료 가용성, coverage 편향, 새로운 기간의 성능 검증이 필요합니다. 이는 문서나 API 상태를 바꿔 해소할 수 있는 문제가 아닙니다.
