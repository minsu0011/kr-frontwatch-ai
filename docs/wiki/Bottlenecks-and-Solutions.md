# 병목과 설계 판단

## 큰 움직임만으로 의미를 설명하기 어려움

시장 특징은 움직임을 표현하지만 공개 촉매나 사건 근거를 대신하지 못합니다. Evidence를 별도로 정리하고 Hybrid 연구로 연결했습니다. 다만 같은 Evidence를 다른 단계에서 다시 독립 확률처럼 가중하는 방식은 배제했습니다.

## 개발 개선과 final reserve의 불일치

개발 자료를 반복 사용한 성과는 새로운 표본에서의 성공을 보장하지 않습니다. 최종 reserve의 label 구성과 양성 근거 coverage가 부족해 필요한 비교가 성립하지 않았습니다. 연구용 artifact를 유지하되 최종 독립 성능과 production 자격을 주장하지 않았습니다.

## 미국 신호를 한국에 그대로 옮길 수 없음

시장 구조와 자료 공급, 사건 label이 달라 미국 계수나 확률을 그대로 쓰면 의미가 어긋납니다. 한국 자체의 특징 분포와 Isolation Forest·adapter를 사용하고 donor는 방향 참고로 제한했습니다. 이 결정이 한국 supervised 성능 검증을 대신하는 것은 아닙니다.

## 근거 미수집을 정상으로 오해하는 문제

자료가 없는 경우는 실제 근거가 없는 경우와 다릅니다. 가용성·시점·coverage를 출력의 일부로 두고, 제한된 자료에서 강한 판정을 하지 않도록 라우팅을 분리합니다.

## 모델 출력과 화면 문구가 달라지는 문제

모델의 순위 지수가 화면에서 확률처럼 보이면 사용 의미가 바뀝니다. 점수 정책과 결과 캐시를 고정하고 화면은 그 의미를 설명하도록 연결합니다. 캐시가 손상되거나 없으면 중단하며 새 점수로 조용히 대체하지 않습니다.

## 서비스 기능과 과학적 성능의 구분

API 응답, UI 탐색, 결과 무결성이 맞아도 탐지 성능이 인증되는 것은 아닙니다. 역사적 replay와 실시간 추론을 구분하고 실시간 학습·예측을 지원한다고 표현하지 않습니다.
