# 미국 연구와 한국 runtime

미국 Stage1은 후보 선별, Stage2B는 시장·근거 Hybrid, Stage3/4는 근거 상태와 출력 결정을 다룹니다. 독립 평가의 label·coverage 한계는 남아 있습니다.

한국 runtime은 별도의 24-feature Isolation Forest와 fitted adapter입니다. 미국 모델의 계수 대신 특징 방향을 참고하며 한국 지수는 사건 확률이 아닙니다.

고정 결과 API와 지정 capsule replay를 구분합니다. API 구현 성공은 실시간 추론이나 과학적 성능 검증 완료를 의미하지 않습니다.
